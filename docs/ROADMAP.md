# 开发方向（ROADMAP）—— 第一性原理版

> **2026-11-14 重写。** 项目定位收敛为一句话：**站长自己写、自己看的个人博客**。
> 产品问题的第一性推演只剩三问：写作顺不顺？读者读得顺不顺？数据和站点安不安全？
> 凡是「让别人部署这个项目」「让一群人互动」的问题，都不再是问题。
>
> 本版取代 2026-11-10 的减法版：那版砍掉的是「不打算做的事」，这版砍掉的是「支撑那些事的代码」。
> 精简执行记录见 [PROPOSAL-SIMPLIFY-2026-11-13.md](./PROPOSAL-SIMPLIFY-2026-11-13.md)。

## 一 · 现在的系统是什么（精简后的骨架）

```
写作        后台编辑器（MD / 富文本 / 插件）· 微博随手记 · 公众号采集 · 定时发布 · TG 发博
阅读        两主题（wechat 双站在用 / minimal）· 全文搜索（FTS5）· 口令解锁（两档站级口令）
互动        评论（游客 + QQ 头像）· 留言板 · 点赞 · IP 属地 · 外链中间页
数据安全    每晚自动备份 · 整站搬家包 · WordPress 迁入 · 回收站 · 媒体体检
门户        RSS / JSON Feed / sitemap / llms.txt / robots + AI 抓取策略 · SEO 自定义
运行        甲骨文 Docker 自托管（唯一形态）· 2 分钟自动部署 · 蓝绿切换 · 访客/爬虫统计
```

50 个 src 文件、约 2 万行（含全部内核与两套主题），一个下午仍能通读——这条复杂度预算**继续有效**，
而且比精简前宽裕得多。

## 三 · 不做清单（拍板记录，防止反复重提）

以下各项**连同代码已在 2026-11-13 批次删除**（不只是「不做了」）：

- **会员体系全家**（注册 / 登录 / 积分 / 档位 / 档位时效 / 邀请码 / 排行榜 / 评论圈层 / 铁粉签到 / 付费墙 /
  跨站会员继承 / 会员活动中心 / QQ 绑定卡）：4 个会员 1 个测试号的现实 + 口令改造解耦后，整套代码没有存在理由。
  数据留在库里，回滚即复活。
- **MCP 服务器**：给外部 AI 助手的写入通道；个人使用没有这个调用方。开放 API（externalToken）仍在。
- **更新中心**：自动部署形态下「检查更新」是死重——服务器自己就是最新版。
- **广场（Plaza）**：hub（独立 Worker）+ 站点同步插件 + 控制面收录链路整体删除。
- **多作者**：users 回归纯管理员单账号。单人写作系统不需要角色矩阵。
- **皮肤/主题市场**：双主题在「皮肤」页直接切换，第三方分发面不再维护。

更早的拍板（依然有效）：邮件相关全不做、AMP / hreflang / Google ping 不做、AI 代理生态协议不接、
内容协商不做、运行时安装不做、会员支付闭环不做、内容揭示卡不做、广场 2.0 P3-P5 不做。
